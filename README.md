# Siva Naga Vamsi Parasa — Portfolio

A responsive personal portfolio for a fresher Full Stack Java Developer.

## Included
- Responsive HTML/CSS/JavaScript website
- Orange / white / black visual system
- Mobile navigation
- Smooth scrolling
- Scroll reveal animations
- Hover interactions
- Font Awesome icons
- SEO meta tags + Schema.org Person data
- Open Graph / Twitter social image
- Favicon
- Resume PDF
- Project artwork
- Mailto contact form
- User-supplied portrait

## Run locally
Open `index.html` in a browser. For best results, serve the folder with a local static server.

## Customize
- Replace or add certificates in `index.html`
- Replace training-project descriptions with your exact project details
- Update social links if needed
- Replace `assets/Siva_Naga_Vamsi_Parasa_Resume.pdf` with your final resume when ready
